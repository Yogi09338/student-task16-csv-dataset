# student-task16-csv-dataset
# Load a CSV Dataset

## Day 16 - AI & ML Internship

This project demonstrates how to load and analyze a CSV dataset using Pandas.

## Objective

To learn how to import real-world tabular data for machine learning workflows.

## Tools Used

- Python
- Pandas
- Jupyter Notebook

## Dataset

The project uses an employee dataset containing:

- Employee ID
- Name
- Department
- Salary

## Operations Performed

- Created a CSV dataset
- Loaded the CSV using `pd.read_csv()`
- Displayed the complete dataset
- Displayed the first 5 records using `head()`
- Displayed the last 5 records using `tail()`

## Files

- `Load_CSV_Dataset_Yogesh.ipynb` – Jupyter Notebook
- `employee_data.csv` – Dataset

## Pandas Functions Used

- `pd.DataFrame()`
- `to_csv()`
- `pd.read_csv()`
- `head()`
- `tail()`
